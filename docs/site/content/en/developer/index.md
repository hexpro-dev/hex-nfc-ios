These pages are the engineering reference for Hex NFC, an app from Hex Pro that
reads and writes NFC tags on an iPhone. They assume you know what an NFC tag and
an NDEF record are. If you are new to the code, start with the
[architecture](architecture.md) page for a map of the Swift package. The [chip
support matrix](chip-support-matrix.md) is the reference for what the app does
with a particular chip.
