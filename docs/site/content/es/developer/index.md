Estas páginas son la referencia técnica de Hex NFC, una app de Hex Pro que
lee etiquetas NFC y escribe en ellas desde un iPhone. El código fuente es
público en
[github.com/hexpro-dev/hex-nfc-ios](https://github.com/hexpro-dev/hex-nfc-ios).
Dan por hecho que sabes
qué son una etiqueta NFC y un registro NDEF. Si el código es nuevo para ti,
empieza por la página de [arquitectura](architecture.md), que traza un mapa
del paquete Swift. La [matriz de compatibilidad de
chips](chip-support-matrix.md) es la referencia de lo que hace la app con cada
chip concreto.
