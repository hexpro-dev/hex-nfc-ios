Ces pages constituent la référence technique de Hex NFC, une app de Hex Pro
qui lit et écrit des tags NFC sur un iPhone. Le code source est public sur
[github.com/hexpro-dev/hex-nfc-ios](https://github.com/hexpro-dev/hex-nfc-ios).
Elles supposent que vous savez ce
que sont un tag NFC et un enregistrement NDEF. Si vous découvrez le code,
commencez par la page [Architecture](architecture.md), qui dresse la carte du
package Swift. La [matrice de prise en charge des
puces](chip-support-matrix.md) est la référence pour savoir ce que l'app fait
d'une puce donnée.
