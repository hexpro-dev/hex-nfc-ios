これらのページは、iPhone で NFC タグを読み書きする Hex Pro のアプリ、Hex NFC のエンジニアリングリファレンスです。ソースコードは [github.com/hexpro-dev/hex-nfc-ios](https://github.com/hexpro-dev/hex-nfc-ios) で公開しています。NFC タグや NDEF レコードとは何かを知っている読者を想定しています。コードに初めて触れる場合は、Swift パッケージの全体像を示した[アーキテクチャ](architecture.md)のページから読み始めてください。アプリが個々のチップに対して何を行うかは、[チップ対応表](chip-support-matrix.md)で確認できます。
