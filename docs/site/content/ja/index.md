このサイトには、Hex Pro の無料アプリ Hex NFC のドキュメントがまとめられています。Hex NFC は、iPhone で NFC タグを読み取り、書き込むアプリです。ユーザガイドはアプリを使う人のためのもので、技術文書はアプリのコードを読んだり変更したりする人のためのものです。

## ユーザガイド

[Hex NFC ユーザガイド](guide/index.md)では、アプリでできることと、使うために必要なものを説明しています。タグの読み取り、書き込み、保護から、タグが応答しないときの対処まで、作業ごとにページを用意しています。まずは[最初のタグを読み取る](guide/quick-start.md)から始めてください。

## 技術文書

[アーキテクチャ](developer/architecture.md)は、アプリの開発に携わる開発者向けのページです。Swift パッケージをターゲットごとに説明し、チップを識別するしくみや、テストでチップのシミュレーターが実物のタグの代わりになるしくみにも触れたうえで、コードが従う規約で締めくくります。

アプリで使うタグを買う前や、タグが思いどおりに動かないときは、[チップ対応表](developer/chip-support-matrix.md)を読んでください。表はタグのファミリーごとに分かれています。FeliCa の表は読み取りと書き込みだけを扱い、ほかの表はパスワードによる保護、完全ロック、メモリダンプも扱います。そのページでは、それぞれの結果が実物のタグで確認済みかどうかも示しています。

## サポートを受ける {#get-help}

タグをスキャンまたは書き込みできないときは、[タグをスキャンまたは書き込みできない場合](guide/troubleshooting.md)で、アプリが表示する各メッセージとその対処法を順に説明しています。アプリの料金や動作する iPhone については[よくある質問](guide/faq.md)を参照してください。

アプリでは、ホーム画面の歯車ボタンをタップし、**フィードバックを送信**をタップします。メッセージは Hex Pro に直接届き、送信前にフォームに一緒に送られる内容（アプリのバージョン、iOS のバージョン、デバイスの機種、言語）が表示されます。[support@hex.pro](mailto:support@hex.pro) へのメールや、[hex.pro のお問い合わせフォーム](https://hex.pro/ja/contact?topic=support)でも連絡できます。不具合報告や新しいチップへの対応のリクエストは、[GitHub の Issues](https://github.com/hexpro-dev/hex-nfc-ios/issues) でも受け付けています。Hex Pro への連絡方法は、[ヘルプページ](https://apps.hex.pro/ja/hex-nfc/support)にまとめています。

## プライバシーポリシーと利用規約

Hex NFC の[プライバシーポリシー](https://apps.hex.pro/hex-nfc/privacy)と[利用規約](https://apps.hex.pro/hex-nfc/terms)は apps.hex.pro で公開しています。どちらについても、ご質問は [support@hex.pro](mailto:support@hex.pro) までお送りください。

## セキュリティ上の問題の報告

脆弱性は、公開のフォーラムやイシュートラッカーではなく、[security@hex.pro](mailto:security@hex.pro) に非公開で報告してください。Hex Pro は 72 時間以内に報告の受領をお知らせし、その後、報告者と協力して修正を進め、一般公開の日程を決めます。問題は、修正がリリースされた時点か、報告から 90 日後のいずれか早いほうで公開されます。報告者が望まない場合を除き、報告者の名前をクレジットとして記載します。
