这些页面是 Hex NFC 的工程参考资料。Hex NFC 是 Hex Pro 推出的一款应用，用于在 iPhone 上读取和写入 NFC 标签。源代码公开在 [github.com/hexpro-dev/hex-nfc-ios](https://github.com/hexpro-dev/hex-nfc-ios)。这些页面假定你已经了解 NFC 标签和 NDEF 记录是什么。如果你刚开始接触这份代码，请先阅读[架构](architecture.md)页面，了解 Swift 包的整体结构。要查阅应用对某款芯片会做些什么，请参阅[芯片支持矩阵](chip-support-matrix.md)。
