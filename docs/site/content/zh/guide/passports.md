电子护照把照片页上的内容存储在芯片中：姓名、号码、日期和照片。Hex NFC 读取这枚芯片，并在一个界面上列出读到的内容。只有提供印在护照内的三项信息，芯片才会开放。第一次贴合找到芯片后，应用会要求你提供这三项信息。读取结果只在该界面打开期间保留，不会更久。

开始之前，你需要在能读取 NFC 标签的 iPhone 上从 App Store 安装应用，还需要护照本身。[读取你的第一枚标签](quick-start.md)介绍了如何安装应用并读取一枚标签。

将护照翻到照片页，放在手边。护照号码、出生日期和到期日期都印在这一页上。你可以用相机扫描这些信息，也可以手动输入。照片页是你查看这些信息的地方，而不是放手机的地方。电子护照的封面上印有芯片标志，即一个内含圆圈的小长方形。没有这个标志的护照不带芯片，这里介绍的方法都无法读取它。

## 读取护照 {#read-a-passport}

::::steps
:::step[打开扫描界面]
在 Hex NFC 主屏幕上点按**扫描**。扫描界面随即打开，显示“将标签贴近 iPhone 顶部”。
:::

:::step[将护照贴近 iPhone]
合上护照，将 iPhone 顶部平贴在护照封面上，保持不动。根据护照的不同，天线可能位于封面、封底或照片页中。如果几秒钟后没有反应，请试试封底，再试试翻开的照片页。第一次贴合会识别芯片的类型，然后结束，iOS 扫描面板也随之关闭。此时扫描界面显示“已检测到护照”，并列出芯片解锁所需的三个栏：**护照号码**、**出生日期**和**有效期至**。它们上方是**扫描照片页**，可以用相机填写全部三项。[用相机扫描信息](#scan-the-details-with-the-camera)介绍了这种方式，它可以代替接下来的两个步骤。
:::

:::step[输入护照号码]
在**护照号码**中输入照片页上的号码，包括其中的字母。输入之前，该栏显示“例如 PA1234567”。
:::

:::step[选择两个日期]
点按**出生日期**，选择照片页上印的日期，然后对**有效期至**执行同样的操作。每个日期选择器打开时显示的都是应用选定的起始日期，因此除了日，也要检查年份。到期日期是护照失效的日期，而不是签发日期。
:::

:::step[开始读取]
点按**读取护照**。护照号码栏为空时，该按钮不会开始读取。
:::

:::step[再次将护照贴近 iPhone]
将护照贴近 iPhone 顶部，并保持不动。扫描面板会依次显示“正在连接你的护照…”“正在用你的信息解锁…”“正在读取护照数据…”和“就快好了…”来表示读取进度。读取完成后，**护照**界面打开。
:::
::::

看完所需的信息后，点按**关闭**。

## 用相机扫描信息 {#scan-the-details-with-the-camera}

**扫描照片页**会从照片页底部的两行机读码中读取护照号码和两个日期，这两行由大写字母、数字和成排的 < 符号组成。没有快门按钮：相机一读出这些信息，就会立即记下。

::::steps
:::step[打开相机]
在扫描界面上，第一次贴合找到护照后，点按**扫描照片页**。首次使用时，iOS 会询问是否允许 Hex NFC 使用相机。相机打开后，标题为“扫描照片页”。如果你不允许使用相机，界面则会显示“需要相机访问权限”。
:::

:::step[将照片页对准框内]
将护照翻到照片页，把 iPhone 举在它上方。界面会显示一个照片页轮廓，轮廓底部有一个框，并显示“将照片页底部那两行字母和 <<< 放入框内。”移动手机，直到页面与轮廓对齐，那两行文字位于框内。界面显示“请保持不动”时，请拿稳手机。随后会出现一个对勾，界面显示“已识别”以及号码和两个日期，片刻之后你会回到扫描界面。
:::

:::step[核对信息]
此时，一张标题为“已从照片页读取”的卡片会取代这几个栏，显示号码和两个日期。请对照照片页逐项核对。要更正某一项，请点按**编辑**：卡片会换回这几个栏，并填入相机读到的内容。如果照片页上的某个日期没有印出日或月，就不会出现**编辑**。要再次使用相机，请点按**重新扫描**。
:::

:::step[开始读取]
点按**读取护照**。合上护照，将它贴近 iPhone 顶部，方法与[读取护照](#read-a-passport)的最后一步相同。
:::
::::

如果框内几秒钟都没有识别到内容，界面会显示“仍在查找。请倾斜页面避开强光，或试试手电筒。”通常是照片页塑料覆膜上的反光造成的，点按界面顶部的手电筒按钮可以照亮页面。要离开相机并手动输入信息，请点按**改为手动输入**。

如果 Hex NFC 的相机访问权限已关闭，界面会显示“需要相机访问权限”。点按**打开设置**可以打开权限，也可以点按**改为手动输入**。

## 「护照」界面显示的内容

该界面为只读。只有芯片提供了相应内容的行才会出现，因此存储内容较少的护照，显示的界面也较短。

- 顶部的护照本显示芯片中的照片，以及护照上印的两行机读码。有些护照以 iOS 无法读取的格式存储照片，这时护照本中会显示一个灰色人像来代替照片。界面上的其他内容不受影响。
- **护照详情**下列出姓氏、名字、护照号码、国籍、签发国、出生日期、性别和到期日期。
- 如果芯片中有安全对象，会显示**数据完整性**卡片。
- 如果芯片中存有签名图像，且 iPhone 能够显示，会显示**签名**卡片。有些护照以 iOS 无法读取的格式存储该图像，这时不会显示该卡片。
- **附加信息**下列出某些护照附带的额外内容，包括出生地、地址、电话、职业、签发机关和签发日期。
- 底部的卡片将芯片名称显示为“电子护照”，将其系列显示为“eMRTD (ISO/IEC 14443-4)”。其他芯片会报告更多信息，详见[芯片支持矩阵](../developer/chip-support-matrix.md)。

## 数据完整性检查能告诉你什么

如果芯片提供了哈希列表，应用会为读到的数据自行计算哈希，并将两者进行比较。之后，**数据完整性**卡片会显示“可能未被篡改”或“可能被篡改”，界面顶部的护照本上也会显示同样的文字。该卡片还会列出它检查过的数据组、所用的哈希算法，以及任何不一致的数据组。

卡片会说明这种比较的意义：“各数据组与芯片安全对象中的哈希列表一致。该对象自身的签名未经验证,因此这既不能证明数据未被改动,也不是对护照真伪的核验。”

:::important[两种结论都不能说明护照是真实的]
Hex NFC 不会检查是谁签署了芯片中的数据。“可能未被篡改”只表示芯片内容自身一致，而任何写入了整枚芯片的人都能做到这一点。
:::

## 信息未能解锁护照时

扫描界面会把原来的提示换成红色的“这些信息未能解锁护照。请对照照片页核对后重试。”你输入的内容会保留在各栏中，相机读取的信息也会保留在卡片中。请对照照片页逐项核对，然后点按**读取护照**，再次将护照贴近 iPhone。

如果信息来自相机，并且相机为号码找到了另一种可能的识别结果，提示则会改为“这些信息未能解锁护照。相机可能读错了一个字符，下次尝试将使用该号码的另一种识别结果。”卡片随即显示这一识别结果。请对照照片页核对，然后点按**读取护照**，再次将护照贴近 iPhone。所有识别结果都尝试过之后，卡片会回到第一种结果，提示也会恢复为上面那条。如果卡片上的内容仍与照片页不符，请点按**编辑**进行更正，或点按**重新扫描**。

- 逐个字符输入护照号码，包括其中的字母，不要加空格。
- 检查两个日期的年份。日期选择器停在错误的年代时，乍看之下仍像是正确的。
- 保持信息不变，再试一次。读取中途断开时，也会显示同样的提示，更稳地再贴合一次通常就能解决。

如果贴近护照时毫无反应，说明芯片没有应答，请参阅[标签无法扫描或写入时](troubleshooting.md)。第一次贴合也可能显示“已检测到标签”并打开**标签**界面。这表示 iPhone 接触到了芯片，但没有识别出它是护照，Hex NFC 无法将这枚芯片作为护照读取。日本交通卡会打开**交通卡**界面，详见[读取交通卡](transit-cards.md)。

## 应用保留的内容

什么都不保留。这三项信息只在那一次读取时用于解锁芯片。扫描照片页时，相机图像在 iPhone 上处理以找出这些信息，不会保存或发送任何图像。信息下方有一条说明：“这些信息保留在你的设备上,仅用于本次读取,绝不会被保存或发送到任何地方。”

芯片返回的内容也是如此。护照的读取结果绝不会加入扫描历史，绝不会导出，也绝不会发送到任何地方。点按**关闭**后，数据会随界面一起丢弃。要再次查看，只能重新读取护照。**护照**界面底部也有类似的说明，内容为：“从芯片读取,仅在本次会话中显示:不保存、不发送,也不验证真伪。”
